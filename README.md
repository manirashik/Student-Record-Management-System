# 🎓 Student Management System (Python + CSV)

A simple yet effective **Student Management System** built using **Python**, with **CSV** as the backend for persistent data storage.  
This project demonstrates full **CRUD operations** (Create, Read, Update, Delete) through a clean, menu-driven **command-line interface**.

---

## 🚀 Features

- **Register Student (Create)**  
  Add a new student record with Roll Number, Name, Age, Email, and Phone.

- **Display Students (Read)**  
  View all student records stored in the CSV file.

- **Find Student (Read)**  
  Search for a student by Roll Number.

- **Modify Student (Update)**  
  Update student details while keeping existing values if input is left blank.

- **Remove Student (Delete)**  
  Delete a student record by Roll Number.

- **Persistent Storage**  
  Student data is stored in `students.csv` and reused across sessions.
